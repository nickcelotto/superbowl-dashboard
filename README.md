# SuperBowl Dashboard

## Overview
I produced this dashboard in my Data Visualization class. It consists of Super Bowl data from 1967 (the first ever Super Bowl) until 2024.

The tableau project consists of many individual visualizations using the Super Bowl data, followed by a complete dashboard with hover functionality.
I have included a the twbx file so you can view the dashboard on your own, as well as a pdf image of the dashboard.
